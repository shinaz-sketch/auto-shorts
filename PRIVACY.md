# Privacy Policy – auto-shorts

Last updated: 16 November 2026

auto-shorts is a personal automation tool operated by Mohammed Shinaz K. It uploads videos to the owner's own YouTube channel and reads that channel's video statistics.

**Data accessed:** only the owner's own YouTube channel, with the permissions to upload videos and read video statistics (views and likes).

**Data collected from other people:** none. The app has no other users, no accounts, and no website that collects information.

**Storage:** an access token is kept as a private secret in the owner's GitHub repository. Video statistics are stored in `state.json` in the same repository, used only to decide what kind of video to make next.

**Sharing:** data is never sold or shared with anyone. It is sent only to Google/YouTube APIs and to Google's Gemini API to generate story text.

**Revoking access:** the owner can revoke access at any time at https://myaccount.google.com/permissions.
